GRISAN ACHARYA — PERSONAL PORTFOLIO

PROJECT FILES
- index.html       Home page
- gallery.html     Gallery and Python practice illustration
- information.html Student details and clickable social links
- contact.html    Contact information and assignment form
- style.css       Shared responsive styling for all four pages
- images/         Your six photographs used by the site

OPEN IN VS CODE (LOCAL TEST)
1. Extract this ZIP to a normal folder.
2. In VS Code choose File > Open Folder and select grisan_portfolio.
3. Install the Live Server extension if you do not have it.
4. Right-click index.html and choose Open with Live Server.
5. Test all navigation links, social links, gallery photos, and form fields.
   You can also double-click index.html, but Live Server is recommended.

PUBLISH ON GITHUB PAGES
Upload the CONTENTS of this folder to the root of your GitHub repository,
including style.css and the complete images folder. Do not upload only the ZIP.
Then open repository Settings > Pages, select Deploy from a branch, choose
main and /(root), and save. Wait for GitHub Pages to publish.
